オープンソースの部品と元のコード

Podtrim 1.0.0 には、LGPL（GNU Lesser General Public License）の部品が入っています。部品ごとの元のコードの置き場を、下に書きます。

This software uses code of FFmpeg licensed under the LGPLv2.1 and its source can be downloaded here.

元のコードの置き場

GitHub の Release podtrim-lgpl-1 に、アプリの ffmpeg の元のコードと組み方、Chromium の FFmpeg と libusb の元のコードを、指紋の一覧 SHA256SUMS と一緒に置いています。アプリの ffmpeg の分は、アプリの中の Podtrim.app/Contents/Resources/licenses/source にも入っています。

アプリの中の ffmpeg・ffprobe

Podtrim.app/Contents/Resources/bin にあります。下の3つの元のコードに手を加えず、build-ffmpeg.sh で静的に組んだ物です。組み直し方は BUILD.txt にあります。

  • FFmpeg 9.0.2（LGPL 2.1 以降）
    公式: https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz
    SHA-256: 8c3850283eb25fa026482078a04051e0be17347b09ef81a0849bec15a96e002e
  • LAME 4.0（LGPL 2 以降）
    公式: https://downloads.sourceforge.net/project/lame/lame/4.0/lame-4.0.tar.gz
    SHA-256: 3df5124d5ad3a98312ffd7ba6a9b36230e4f8a3e66d3ce0f425e336c32d216eb
  • mpg123 1.33.7（LGPL 2.1）
    公式: https://www.mpg123.de/download/mpg123-1.33.7.tar.bz2
    SHA-256: 31d0e35a4ca567ec9b5ebda6c3062bb4435d6d3eacd6ef0d95cadd7854dc03ee

FFmpeg の組み立ての設定:

--disable-autodetect
--disable-doc
--disable-ffplay
--disable-network
--disable-shared
--enable-static
--enable-libmp3lame
--enable-audiotoolbox
--extra-cflags='-I../../deps/include -mmacosx-version-min=13.0'
--extra-ldflags='-L../../deps/lib -mmacosx-version-min=13.0'
--extra-libs=-lmpg123

Electron の中の部品

Podtrim.app/Contents/Frameworks は、Electron 44.9.3（Chromium 152.0.7977.167）の公式の配布物で、手を加えていません。LGPL の部品は次の3つです。

  • FFmpeg（Chromium の物・libffmpeg.dylib）
    公式: chromium/third_party/ffmpeg の 2b68d2babae73714846961fb0ee47e3b3d2e39a9 と、Electron の直し link_with_loader_path.patch
    Release の写しの SHA-256: 02a96e7b62280c5c004a64fcb02e75d0726f6c512930cae6e14cb422fc32f6e2
  • libusb 1.0.17（Electron Framework の中）
    公式: Chromium 152.0.7977.167 の third_party/libusb
    Release の写しの SHA-256: 487456bd30ea05c096a16d4b73c84ba9521c6b9b07a6b8c396ac2beb9b1518a4
  • WebKit から来た部分（Electron Framework の中）
    公式: Electron v44.9.3 と Chromium 152.0.7977.167

WebKit の部分は大きいので、Release には置いていません。上の公式の置き場から落とせます。

Open source components

Podtrim 1.0.0 includes components licensed under the GNU Lesser General Public License (LGPL).

  • Podtrim.app/Contents/Resources/bin/ffmpeg and ffprobe: FFmpeg 9.0.2 (LGPL 2.1 or later), statically linked with LAME 4.0 (LGPL 2 or later) and mpg123 1.33.7 (LGPL 2.1), all unmodified. Their source code, build-ffmpeg.sh and BUILD.txt are in the GitHub release podtrim-lgpl-1 and in Podtrim.app/Contents/Resources/licenses/source.
  • Podtrim.app/Contents/Frameworks: the unmodified official build of Electron 44.9.3 (Chromium 152.0.7977.167). Its LGPL parts are Chromium's FFmpeg in libffmpeg.dylib and libusb 1.0.17, whose source is in the release, and the WebKit-derived code in Electron Framework, whose source is in Electron v44.9.3 and Chromium 152.0.7977.167.
  • MPL 2.0 parts: symphonia and others in Electron Framework, whose source is in Chromium 152.0.7977.167, Eigen in ONNX Runtime 1.31.0, whose source is in eigen-mirror 1d8b82b0740839c0de7f1242a3585e3390ff5f33, and Eigen 5.0.1 in sherpa-onnx 2.0.2, whose source is eigen-5.0.1.tar.gz.
